Projects

Ultimate Tic Tac Toe AI

View Project

I built an AI for Ultimate Tic Tac Toe using depth-limited minimax with alpha-beta pruning, iterative deepening, and move ordering.

I designed a heuristic evaluation function using mini-board control, macro-board line scoring, center and corner weighting, and active-board pressure. I also implemented state normalization, legal move generation, terminal-state detection, and time-limited search.

Skills: Python, minimax, alpha-beta pruning, heuristic design, adversarial search, iterative deepening, state-space search, algorithm optimization, and runtime-constrained decision making

Guard Shift

View Project

I built a top-down stealth game in Python and Pygame with guard behavior driven by A* search over a grid-based state space.

Guards dynamically replan paths across patrol, investigate, chase, and search states. The game also includes noise-triggered responses, door-based path blocking, alert escalation, and multiple levels.

Skills: Python, Pygame, A* search, pathfinding, state machines, heuristic search, game AI, dynamic replanning
